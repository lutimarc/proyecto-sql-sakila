Proyecto SQL: lógica y consultas

Análisis de una tienda de alquiler de películas con PostgreSQL.

Archivos

- `BBDD_Proyecto_shakila_sinuser.sql`: base de datos facilitada para el proyecto, con estructura y datos.
- `consultas_resueltas.sql`: soluciones numeradas de los 65 ejercicios del enunciado.
- `EnunciadoDataProject_SQL.Lógica.pdf`: enunciado del proyecto.

Cómo ejecutarlo

1. Crea una base de datos en PostgreSQL.
2. Ejecuta `BBDD_Proyecto_shakila_sinuser.sql` dentro de esa base de datos.
3. Abre `consultas_resueltas.sql` y ejecuta los ejercicios.

Las tablas temporales de los ejercicios 51 y 52 solo existen durante la sesión en la que se crean.
